# 星辉召唤

浏览器单人抽卡与闯关游戏，使用原生 JavaScript 和 Vite。无需账号或付费，进度保存在当前浏览器的 localStorage 中。

## 开发

需要 Node.js 20.19+ 或 22.12+（云端已提供 Node.js 24）。

```sh
npm ci
npm run dev
npm test
npm run build
```

## 玩法

- 初始赠送 3,000 星钻和三位 R 角色。
- 单抽 150 星钻；十连 1,500 星钻，至少一位 SR 或更高。
- 基础概率：R 70%、SR 24%、SSR 5%、UR 1%。第 50 抽保底 SSR，获得 SSR 或 UR 会重置保底计数。
- 重复角色每次提升 8 战力，最多提升十次。
- 在「我的角色」编成最多三人的队伍，通过「冒险关卡」挑战十二关。
- 战斗伤害为队伍战力的 90%–110%；首通奖励 350 星钻，重复通关奖励 60 星钻。
- 通关当前关卡后解锁下一关。可以反复挑战已解锁关卡获取资源。

这是本地单人原型，没有联网、支付或云端存档。清除浏览器站点数据会重置进度。角色图像使用 CSS 与符号绘制，无需外部素材。

## 界面与演出

角色卡面使用本地 SVG 绘制，包含动态星光、稀有度光效、翻牌揭晓和战斗攻击演出。页顶可以开启合成音效（默认关闭）。支持减少动态效果的系统设置；抽卡可选择全部揭晓，也可直接关闭演出。存档键保持不变，更新后原有进度可以继续使用。

## 更新 GitHub Pages

```sh
npm run build:pages
```

该命令重新构建并把网页、脚本、样式合并至 `docs/index.html`。提交更新后的文件并推送至 `main`，GitHub Pages 会从 `/docs` 自动部署。
